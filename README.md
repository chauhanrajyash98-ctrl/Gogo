# Gogo ki Duniya

Ek chhota platformer game jo browser mein chalta hai: TV, laptop aur mobile par.

**Khelo:** https://chauhanrajyash98-ctrl.github.io/Gogo/

- iPhone: Safari mein link kholo, Share → "Add to Home Screen". Ek baar khulne ke baad offline bhi chalega.
- Controls: ◀ ▶ chalna, ▲ / Space / OK kudna, P / Esc / Back rukna. Mobile par screen par buttons aate hain.

## Toofani Takkar (fighting game)

**Khelo:** https://chauhanrajyash98-ctrl.github.io/Gogo/ladai/

4 original fighters (Kekda Kaptaan, Veer Bahadur, Tara Toofan, Chhotu Cheeta), computer ke saath ladai, combo aur special moves.
- Keyboard: teer = chalo/kudo/jhuko (peeche = block), J mukka, K laat, L special
- TV remote: OK = mukka (baar baar = combo), OK daba ke rakho = special
- Mobile: screen par buttons
